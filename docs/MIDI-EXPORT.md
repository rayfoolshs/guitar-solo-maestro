# MIDI export

`Chart ▾ → Export MIDI…` writes a Standard MIDI File of the current arrangement. It is
generated from the same `buildScore()` events the transport plays, so what you export is
what you hear.

## File summary

| Property | Value |
|---|---|
| Format | Standard MIDI File, **format 1** (multi-track) |
| Division | **480 ticks per quarter note** |
| Tracks | 1 conductor + 3 part tracks |
| File extension | `.mid` |
| MIME type | `audio/midi` |
| Filename | `slugify(chart.name).mid` |

## Tracks and channels

| Track | Channel | GM program | Name |
|---|---|---|---|
| 1 | — | — | Conductor (tempo + time signature) |
| 2 | 1 (0-based 0) | 0 Acoustic Grand Piano | Piano |
| 3 | 2 (0-based 1) | 32 Acoustic Bass | Bass |
| 4 | 10 (0-based 9) | — (GM percussion) | Drums |

Drum note numbers are the same as playback: 36 kick, 38 snare, 42 closed hat, 44 pedal
hat, 46 open hat, 49 crash, 51 ride, 37 cross-stick, 70 shaker.

## Conductor track

| Event | Payload |
|---|---|
| Track name | `FF 03` + `"Conductor"` |
| Tempo | `FF 51 03` + 24-bit microseconds per quarter (`60 000 000 / tempo`) |
| Time signature | `FF 58 04` + numerator, `log2(denominator)`, 24, 8 |
| End of track | `FF 2F 00` |

Examples: 4/4 → `04 02 18 08`; 3/4 → `03 02 18 08`.

## Tick math

Ticks are `round(beats × 480)`.

| Musical position | Ticks |
|---|---|
| Quarter note | 480 |
| Eighth note | 240 |
| Off-beat eighth (straight) | 240 |
| Shuffle off-beat (2/3 beat) | 320 |
| Half bar (two chords per bar) | 960 |

Swing is applied by `buildScore()` before export, so a shuffle or swing feel is baked into
the beat positions — no MIDI groove/tempo map is needed.

## Note messages

- Note on: `0x90 | channel`, pitch, velocity (1–127).
- Note off: `0x80 | channel`, pitch, 0.
- Each note gets a minimum duration of **1 tick**.
- At the same tick, **note-offs sort before note-ons**, so repeated pitches retrigger
  cleanly.
- Delta times use standard variable-length quantity (VLQ) encoding.
- No running status is used; every message carries its status byte.

## What is included

- The **visible bars** only (`chart.visibleBars`), matching playback.
- Piano, bass and drums, including comping, walking lines, patterns and swing.
- Tempo and time signature from the chart.
- The chart's current transposition — chords are rewritten before scoring, so the export
  follows whatever key the chart is in.

## What is not included

- Count-in click.
- Loop range or loop markers.
- Mixer volume/mute settings (notes are exported unmodified).
- Piano octave shift — actually applied to the note pitches before export, so the exported
  notes match what you hear.
- Any melody or lyrics.

## Verifying a file

The exported file is a valid format-1 SMF; on macOS `file` reports:

```
Standard MIDI data (format 1) using 4 tracks at 1/480
```

The first bytes are:

```
4d54 6864 0000 0006 0001 0004 01e0   MThd ........
4d54 726b ...                        MTrk ...
```

## Tests

`tests/midi.test.ts` parses the generated bytes and checks:

- `MThd`, length 6, format 1, four tracks, division 480.
- Tempo decodes back to the chart tempo; 4/4 and 3/4 signatures.
- One note-on per scored event on each channel.
- Every note-on has a matching later note-off.
- Shuffle ride lands on tick 320.
- Every track ends with `FF 2F 00`.

## Implementation

`src/arrange/midi.ts`:

- `buildMidiFile(chart, events): Uint8Array`
- `downloadMidi(chart, events): void`
- `MIDI_PPQ` constant
- `TrackWriter` handles delta times, meta events and the end-of-track marker.

No external MIDI library is used.
